# E-Commerce Customer Analytics

## Project Overview

This project analyzes e-commerce customer behavior, sales trends, and product performance using SQL, Python, and Tableau.

## Tools Used

- PostgreSQL
- Python
- Pandas
- Tableau
- Git/GitHub

## Key Skills Demonstrated

- SQL joins
- Window functions
- CTEs
- Data cleaning
- Exploratory analysis
- Dashboard development

## Key Insights

- Top-performing states generated the highest revenue
- A small percentage of customers contributed most sales
- Revenue trends showed seasonal spikes
- Product review scores correlated with revenue performance
